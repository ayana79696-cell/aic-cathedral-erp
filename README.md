# AIC Cathedral Primary School ERP

Production school management platform built with Next.js, TypeScript and Supabase.

## Modules
Dashboard, Students, Parents, Staff, Academic Setup, Exams & CBC, Results, Attendance, Finance, HR, Procurement, Inventory, Transport, Communications, Reports, User Management and Audit Logs.

## Stack
- Next.js + TypeScript
- Supabase Auth + PostgreSQL + RLS + Storage
- Vercel deployment

Never commit secrets. Configure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in Vercel/local environment variables.
