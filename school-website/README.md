# AIC Cathedral School Website + Parent Portal

This is a **separate application** from the AIC Cathedral ERP.

- Public school website: `/`
- Parent Portal login: `/parent-portal`
- Parent dashboard shell: `/parent-portal/dashboard`
- Branding: AIC Cathedral Primary School, Gilgil
- Logo: `public/aic-cathedral-logo.svg`
- Backend target: the existing AIC Cathedral Supabase project

## Deployment

Deploy this folder as its own Vercel project by setting the Vercel **Root Directory** to `school-website` in the shared GitHub repository, or move this folder to a dedicated website repository.

The ERP root application remains a separate deployment and now opens its staff login instead of the public school website.
